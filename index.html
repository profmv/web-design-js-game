Quando o Design destrava o Código

O app Agenda & FilaZero do Campus entra no ar hoje, mas a interface está desalinhada e o JavaScript parou de responder. Reúna seu Squad para corrigir o visual, programar os algoritmos e destravar todas as 8 etapas do lançamento.

[UI/UX] Arquiteto(a) de Interface Ajusta escala modular, ritmo de 8px, contraste WCAG, padrões de usabilidade e Auto Layout para gerar os Design Tokens.
[DEV JS] Engenheiro(a) JavaScript Programa regras de escala, ordenação, box model, estados de botão, filtros seguros, validação de formulário e layout.
[PO] Conselheiro(a) de Produto Conduz a Prancheta Oficial (#1) com as regras do estúdio, fornece o código verificador da etapa e assina o Handoff.
[QA] QA Hunter (Auditor) Testa a interface e o código de outros Squads com o Passaporte de QA (#2) para encontrar falhas antes da entrega.

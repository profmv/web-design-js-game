[CHAVE DEV JS + NIELSEN] Cola Rápida para o Conselheiro

Heurística de Nielsen (M7) Como diferenciar no Tribunal
#1 Visibilidade do status Tela parada 20s sem mostrar "Carregando..."
#2 Mundo real (linguagem) Jargão ("vínculo discente") em vez da língua do aluno.
#3 Controle e liberdade Apagou sem querer e não existe botão "Desfazer".
#4 Consistência e padrões "Salvar" azul na Tela 1 vira "Gravar" verde na Tela 2.
#5 Prevenção de erros (ANTES) Deixar digitar data 31/02/2026 sem travar ANTES.
#6 Reconhecer vs lembrar Exigir decorar código ADS-204 sem mostrar lista.
#9 Recuperar de erros (DEPOIS) Mensagem técnica Erro 0x80041 sem instrução.

[COLA JAVASCRIPT] Padrões para o Dev JS (M1 a M8)

M1 (Escala): Math.round((base * Math.pow(razao, passo)) / 4) * 4; entrelinha 1.25x (título) / 1.5x (texto).
M2 (Peso): .sort((a,b) => b.tamanho - a.tamanho || b.peso - a.peso || b.contraste - a.contraste).
M3 (Box Y): Somar alturas e espaços em cascata: yBtn + cfg.btn + cfg.pad = altura total (256).
M4 (Estado): Se novasVagas <= 0: bloqueado: true, rótulo "Inscrições encerradas".
M5 (Filtro): Descartar item.darkPattern === true e usar item.titulo.toLowerCase().includes(termo).
M6 (Wire): camadas.filter(c => c.decorativo !== true).map(c => c.sigla).join("-").
M7 (Form): Bloquear nome vazio (#5), 31/02/2026 (#5) e !cursosValidos.includes(...) (#6).
M8 (Layout): alturaCard = padCard + altConteudo + gapCard + altBotao + padCard (328x296-N11).
